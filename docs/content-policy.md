# 内容规则

这里是聊天表情墙。收纳与蓝色大肥鱼有关、可以用于日常对话的情绪反应、动作、吐槽和趣味表情。无字的明确反应图也可以提交。

暂不收纳：

- 涩图、性暗示图、泳装或内衣展示，以及主要突出身体部位的图片。
- 以观赏为主的角色立绘、写真式插画、壁纸，与聊天表情用途无关的图片。
- 针对性别或其他群体的贬损、骚扰，以及令人不适的暴力或色情内容。
- 未附来源、刻意去除署名水印或违反作者明确转载要求的素材。

这些规则适用于所有用户，不以某一种性别或某个角色风格作为通过标准。角色穿着、构图、文字和实际用途应一起判断，不能仅靠标签或自动图片算法放行。

每次新增或替换都需要维护者看图审核；CI 只做格式、结构、重复和文本辅助检查，不宣称能自动审核内容。边界不明确的图先不收纳，可在 PR 中讨论。

截图预处理不改变上述收纳规则。新增、替换或重新处理图片时，需同时检查投稿原图和处理结果；不得用裁剪隐藏作者水印、删掉改变含义的文字或掩盖原图不适合收录的问题。自动裁边的报告只是辅助，不能代替看图。

发现不合适内容、错误署名或希望下架，请通过[内容问题入口](https://github.com/pluveto/DeepSeek-chan/issues/new?template=content.yml) 提供条目 ID 和原因，不必重复上传问题图片。移除生效后，本站索引不再包含该条目；公开 Git 历史、fork、缓存和已下载副本无法随普通删除一并抹除。
