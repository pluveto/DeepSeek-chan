ABOUT THIS LITTLE COLLECTION

一面属于社区的表情墙。

DeepSeek-chan 收集蓝色大肥鱼 / DeepSeek 同人聊天表情，让大家更方便地找到、收藏和分享一份心情。网站位于 deepseek-chan.ry.rs。

本项目由社区维护，不是 DeepSeek 官方网站，也不代表 DeepSeek 官方立场。名称与相关标识属于各自权利人。

蓝色大肥鱼从哪里来

角色原作与二次创作的来源说明可参考 蓝色大肥鱼档案馆的版权与来源记录，其中记录了原作「上善无形」及二设「ZipZipPipe」。不同表情也可能包含其他作者的创作，请以各条目展示的来源和署名为线索进一步核实。

特别感谢 EDMOK / 蓝色大肥鱼档案馆的整理与分享，也感谢每一位原作者。首批收录图片逐张保留档案馆的具体文件链接，方便追溯；档案馆是整理来源，不代表其中每张图片均由其创作。如果署名遗漏或记录有误，欢迎帮助修正。

代码开源，素材权利各自保留

本项目的代码采用 MIT 许可证。图片、角色和其他创作内容的权利归原作者或相关权利人所有，不因被收录到开源仓库而自动适用 MIT 或其他统一许可。

条目中的授权说明仅用于记录已核实的信息。下载、转载或用于其他用途前，请查看原始来源的实际许可；本站不代替原作者授予使用权。

静态图片可能经过裁去截图空边和缩小尺寸的整理，网站不会放大图片或使用 AI 重画。详情页会说明已做的裁剪或尺寸调整，并始终提供原始投稿下载；来源与署名继续保留。动图保持原样。具体规则见贡献指南。

发现问题，帮助我们改正

如果内容侵犯你的权利、来源不准确，或不适合聊天表情收藏，请 提交 Issue 反馈，附上条目链接、具体问题和相关证明。也可以通过 PR 直接修正信息或请求移除。

下架后，条目会从当前网站和搜索索引移除。仓库历史或第三方副本中可能仍存在旧文件；需要进一步处理历史文件时，请在反馈中说明。

简单、公开地一起维护

图片、文字、标签与来源通过 GitHub PR 维护，一份 PR 可以包含多项变更。自动检查辅助去重和生成展示资源，最终收录仍由维护者人工审核。我们仅收录日常聊天表情，暂不收录涩图或以身体展示为主的图片。

搜索依据已录入的文字、标题和标签进行匹配。收藏保存在当前浏览器中；清除浏览器数据或更换设备后不会自动同步。
